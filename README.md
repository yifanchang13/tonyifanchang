# Yifan Chang — Personal Website

[Visit the website](https://yifanchang13.github.io/tonyifanchang/)

Academic homepage of Yifan Chang, a Finance Ph.D. candidate at Tsinghua University PBC School of Finance.

## Files

- `index.html`: introduction, research, papers, and contact details.
- `bio.html`: education, awards, fellowships, and teaching.
- `my-cat.html`: cat photographs.
- `styles.css`: shared layout and responsive styles.
- `*.jpg` and `favicon.svg`: portrait, cat photographs, and favicon.
- `*.woff2` and `LICENSE.txt`: self-hosted Charter webfonts and their original license.

## Preview and update

Open `index.html` in a browser, or run `python3 -m http.server 8000` from the repository and visit `http://localhost:8000/`. No build step or installation is needed. Edit the HTML and CSS, then commit to `main` to update the site.

GitHub Pages publishing source: **main / (root)**. The CV is stored separately in Google Drive with access restricted to its owner; visitors request permission, and the owner approves access. The PDF is not included in this repository.

Content and photographs were migrated from [Yifan Chang's Google Site](https://sites.google.com/view/yifan-chang/home). Charter webfonts are from [Butterick's Practical Typography](https://practicaltypography.com/charter.html); retain `LICENSE.txt` when redistributing them.
